# Golden Bean Roastery — Business Landing Page

A responsive marketing landing page for a fictional specialty coffee roastery in Kumasi. Built to demonstrate front-end fundamentals with no framework or build step required.

## Live demo
Open `index.html` directly in any browser — no server needed.

## Features
- Custom type pairing (Fraunces + Work Sans) and a warm, earth-tone palette built specifically for the subject
- Hero, origin strip, roast product grid, and a four-step process explainer
- Scroll-reveal animation on product cards and process steps (IntersectionObserver)
- Smooth-scrolling in-page navigation
- Fully responsive down to mobile (single-column layout under 860px)

## Tech stack
- HTML5
- CSS3 (custom properties, CSS Grid, Flexbox)
- Vanilla JavaScript (no dependencies)

## File structure
```
golden-bean/
├── index.html    # Markup and content
├── styles.css    # All styling, palette, and responsive rules
└── script.js     # Smooth scroll + scroll-reveal behavior
```

## Notes
This is a static site with placeholder business content — swap the copy, prices, and origin details to adapt it for a real client.
